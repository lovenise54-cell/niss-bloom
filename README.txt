NISS BLOOM — FREE PUBLISH VERSION

1. Open GitHub and create a new public repository, e.g. niss-bloom.
2. Upload index.html and the assets folder.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. GitHub will give you a free website address.
5. Replace assets/bouquet.svg with your real bouquet photo (name it bouquet.jpg) and change the two image references in index.html to assets/bouquet.jpg if desired.

PAYMENT
The site uses Cash App: $LoveniseJp.
Customers are shown the 50% deposit and a Cash App button.
After payment, they can text the business number.

IMPORTANT
This free version intentionally does not store customer orders in a server database. Orders are kept in the customer's browser and the payment confirmation is sent by text. Do not collect sensitive information.


ADMIN PAGE
Open your published site with /admin.html.
Example: https://YOUR-USERNAME.github.io/niss-bloom/admin.html
The included password is NissBloomAdmin.

SECURITY NOTE
This is NOT secure admin authentication. GitHub Pages is static/public, so a password stored in admin.html can be viewed by someone who knows how to inspect the site. Do not use it for sensitive information. A real private admin dashboard with orders across customers requires a server/database.
